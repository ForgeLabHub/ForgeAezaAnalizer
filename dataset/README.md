# Данные

data.json — синтетический снимок из 10 аккаунтов, 30 услуг и 100 транзакций. Приложение импортирует его при первом запуске на пустой базе. Новый снимок можно передать через PUT /api/v1/source/snapshot.

## Файлы

- data.json — исходный снимок для приложения.
- generate.py — генератор JSON и SQL.
- 001_schema.up.sql, 001_schema.down.sql, 002_seed.sql — отдельная SQL-схема и начальные данные.

Генерация нового набора:

~~~bash
python3 generate.py --accounts 100 --services 300 --transactions 1000 --seed 42 --out ./generated
~~~

При одинаковых параметрах результат воспроизводится. amount у транзакций не является суммой денег; балансы и цены услуг хранятся в целых евроцентах.
