# Модуль: AI Analyst и ассистент

## 1. Назначение и границы
Отвечает на вопросы по данным через инструменты (tools), а не прямым доступом к базе:
`backend/app/ai/tools/{analytics,customers,scenarios,actions}.py`. Провайдер модели —
заменяемый (`ai/providers/base.py`, реализации `ollama.py`, `mock.py`).
Не делает: не исполняет произвольный SQL, не ходит в данные в обход инструментов, не
работает при `AEZA_AI_ENABLED=0`.

## 2. Сценарии использования
- Вопрос «какие услуги под риском» → вызов инструмента → ответ с цифрами и источниками.
- Ответ без модели (mock-провайдер) в тестах и при отключённом AI.
- Отказ: провайдер недоступен → внятная ошибка, обычные расчёты продолжают работать.

## 3. Контракт
`/api/v1/ai/*`, `/api/v1/model/*` в `backend/openapi.json`. Внутренний контракт —
`ai/service.py` и схемы `ai/schemas.py`; инструменты объявляют вход/выход явно.

## 4. Данные
Собственных таблиц нет: чтение идёт через инструменты, которые вызывают домен
аналитики. Ответы не сохраняются как источник истины — цифры всегда берутся из домена.

## 5. Права
Требуется аутентификация; инструменты доступны только в рамках роли аналитика.
Проверки безопасности входа/выхода — `ai/safety.py` (экранирование, ограничения
контекста).

## 6. Зависимости
Исходящие: домен аналитики, провайдер LLM по HTTP, RAG-индекс (`ai/rag/index.py`).
Входящие: `backend/app/api/routes_ai.py`.

## 7. Конфигурация
`AEZA_AI_ENABLED`, `AEZA_AI_PROVIDER`, `AEZA_AI_MODEL`, `AEZA_AI_BASE_URL`,
`AEZA_AI_MAX_TOKENS`, `AEZA_AI_TIMEOUT_SECONDS`, `AEZA_LLM_*`, `AEZA_OLLAMA_*`.
Выключено по умолчанию: AI — опция, а не условие работы продукта.

## 8. Сборка и отладка
```bash
python -m pytest backend/tests/test_ai.py -q
python -m backend.app.ai.rag --docs ./docs --out backend/data/rag_index.json
```

## 9. Тесты
`backend/tests/test_ai.py`: вызов инструментов, отключённый режим, mock-провайдер,
защита от небезопасного вывода. Проверка «AI не становится источником истины» —
цифры в ответах совпадают с доменом.

## 10. Наблюдаемость
Состояние провайдера видно через `/api/v1/model/*`; ошибки провайдера логируются без
содержимого промптов. Метрики задержек — `/metrics`; таймаут по умолчанию 420 с
заметен оператору как долгие запросы.

## 11. Ограничения и готовность
- Качество ответа не гарантируется; компенсируется тем, что цифры берутся из домена.
- RAG-индекс собирается в образ при сборке — после изменения `docs/` нужна пересборка.
- Готовность: при выключенном AI продукт полностью работоспособен; инструменты не дают
  доступа к данным, недоступным пользователю.
