# Контекст системы

## Что это

Веб-приложение для анализа риска продления услуг и выручки под риском. Оценка риска —
**объяснимая взвешенная эвристика**, а не вероятность оттока: размеченных исходов в
наборе нет. Это ограничение продукта, а не дефект реализации.

## Контекстная диаграмма

```
        ┌────────────┐   ┌──────────────┐   ┌───────────────┐
        │ Аналитик   │   │ Telegram     │   │ Внешний       │
        │ (браузер)  │   │ Mini App/бот │   │ источник      │
        └─────┬──────┘   └──────┬───────┘   │ (снимок)      │
              │ HTTPS           │           └───────┬───────┘
              ▼                 ▼                   │ PUT /api/v1/source/snapshot
        ┌────────────────────────────────────┐      │
        │ web (nginx + React build)          │      │
        └─────┬──────────────────────────────┘      │
              │ /api/v1/*                          │
              ▼                                    ▼
        ┌─────────────────────────────────────────────────────┐
        │ api (FastAPI)                                       │
        │  backend/app: домен аналитики, API, AI, метрики     │
        │  backend/auth: учётные записи, JWT, сессии          │
        └──────┬───────────────────────┬──────────────────────┘
               │                       │
               ▼                       ▼
        ┌──────────────┐        ┌───────────────────┐
        │ PostgreSQL16 │        │ SQLite (auth db)  │
        │ аналитика    │        │ пользователи,     │
        │              │        │ сессии, ключи     │
        └──────────────┘        └───────────────────┘
               │
               ▼ опционально
        ┌────────────────────────────────────────────┐
        │ Ollama/LLM · SMTP · Telegram Bot API       │
        └────────────────────────────────────────────┘
```

## Две базы — осознанное решение

- **PostgreSQL** — предметные данные (аккаунты, услуги, транзакции, агрегаты).
- **SQLite** — только аутентификация (`AUTH_DATABASE`).

Смысл: модуль аутентификации можно использовать и тестировать отдельно, не поднимая
PostgreSQL (`tests/test_auth.py` работает без базы аналитики). Цена: два механизма
резервного копирования, оба описаны в
[operations/deployment.md](../operations/deployment.md).

## Границы поддержки

Заявлено: PostgreSQL 16, Python 3.12, Linux + Docker Compose, Chromium-совместимые
браузеры. Не заявлено: совместимость с другими СУБД, работа без PostgreSQL
(аналитическая часть), масштабирование на несколько реплик api без внешнего состояния
(снимок и кэш живут в процессе).

## Режим отказа внешних систем

| Зависимость | Обязательна | При отсутствии |
| --- | --- | --- |
| PostgreSQL | да | приложение не обслуживает аналитику |
| LLM (Ollama и др.) | нет | AI-функции выключены, расчёты работают |
| SMTP | нет | письма не отправляются |
| Telegram | нет | интеграция выключена |
