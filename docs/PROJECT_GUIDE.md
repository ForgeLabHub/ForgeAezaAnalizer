# Руководство проекта

## Устройство

- frontend/ — интерфейс React и TypeScript.
- backend/app/ — FastAPI, API, импорт данных и расчёты.
- backend/auth/ — учётные записи и сессии.
- dataset/data.json — начальный синтетический снимок.

Docker Compose запускает интерфейс, API и PostgreSQL. Учётные записи и сессии хранятся отдельно в SQLite.

## Данные

Снимок содержит массивы accounts, services и transactions. При первом запуске на пустой базе он проверяется и импортируется. Новый снимок загружается целиком через PUT /api/v1/source/snapshot; при ошибке предыдущие опубликованные данные сохраняются.

Данные синтетические и не содержат размеченной истории оттока.

## Риск и выручка

Риск услуги — взвешенная оценка доступных факторов в диапазоне 0–100. Отсутствующие факторы исключаются из расчёта. Риск клиента равен максимальной оценке его прогнозируемых услуг.

Прогнозируются открытые услуги со статусами active, suspended и prolong_wait. Статусы deleted и blocked уже отражают завершённое состояние и не прогнозируются. Оценка не является вероятностью оттока.

Выручка под риском не влияет на оценку: цена каждого платного продления в выбранном горизонте умножается на риск услуги и учитывается один раз. Денежные поля приложения хранятся в евроцентах; transactions.amount не используется как сумма денег.

## API

Актуальные схемы запросов и ответов доступны по адресу /api/v1/docs. Приватные маршруты требуют Bearer-токен после входа через /api/v1/auth/login. Состояние сервиса: /health и /ready.
