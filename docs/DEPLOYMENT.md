# Развёртывание

## Локальный запуск (основной сценарий)

```bash
git clone https://github.com/Pixelminds-hub/aeza-analizer.git
cd aeza-analizer
chmod +x run.sh
./run.sh
```

`run.sh` создаёт `.venv`, ставит зависимости, импортирует `датасет.zip` при
первом запуске и поднимает сервер на `http://127.0.0.1:8000`.

Опции: `--no-import`, `--reimport`, `--host`, `--port`, `--help`.

Ручной запуск:

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
python -m aeza_analyzer.cli import
python -m aeza_analyzer.cli serve --host 0.0.0.0 --port 8000
```

## Хранилище

По умолчанию SQLite-файл `data/aeza.sqlite` (каталог в `.gitignore`).
Другой путь — `AEZA_DATA_DIR`; внешняя БД — `AEZA_DATABASE_URL` (нужен драйвер).

## Render (если потребуется)

Приложение совместимо с Render как Web Service, но есть **важные оговорки**,
которые нужно учесть до развёртывания:

| Аспект | Состояние | Что делать |
|---|---|---|
| Порт | Render передаёт `PORT` | запускать `uvicorn` с `--port $PORT` |
| Host binding | нужен `0.0.0.0` | `serve --host 0.0.0.0` |
| Диск | **эфемерный** | SQLite будет теряться при рестарте |
| Импорт | выполняется при старте | на эфемерном диске импорт повторяется каждый раз |
| Аутентификация | **отсутствует** | публичный URL позволит менять веса и импорт |

Поэтому **рекомендуется**:

1. Подключить Render Disk, примонтированный в `AEZA_DATA_DIR`, либо
2. Перейти на управляемый PostgreSQL через `AEZA_DATABASE_URL` (организатор
   поставляет совместимую схему в `датасет/001_schema.up.sql`).

Стартовая команда для Render (пример, без секретов):

```
python -m aeza_analyzer.cli serve --host 0.0.0.0 --port $PORT
```

Build: `pip install -r requirements.txt`.
После первого старта выполнить импорт (`python -m aeza_analyzer.cli import`)
или разрешить `run.sh` сделать это.

**Фактическое развёртывание на Render в рамках этой задачи не выполнялось** —
соответствие проверено по коду и требованиям платформы, но не подтверждено
запуском. Не считайте это доказанным деплоем.

## Docker

Docker **не добавлен**: локальный сценарий через `run.sh` проще и достаточен,
а контейнеризация не требуется первичными материалами. Добавлять её «для
галочки» нецелесообразно.

## Переменные окружения

| Переменная | Назначение |
|---|---|
| `AEZA_DATA_DIR` | каталог хранилища |
| `AEZA_SOURCE_ZIP` | путь к архиву |
| `AEZA_DATABASE_URL` | переопределение БД |
| `AEZA_HOST` / `AEZA_PORT` | адрес сервера |
| `AEZA_VENV_DIR` | каталог venv |

Секретов приложение не требует.
