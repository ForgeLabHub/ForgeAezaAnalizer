# Соглашения API

Спецификация: [`backend/openapi.json`](../../backend/openapi.json) — генерируется
(`make openapi`), сверяется в CI (`make openapi-check`). Интерактивная документация
работает на живом инстансе: `/api/v1/docs`.

## Базовые правила

| Правило | Деталь |
| --- | --- |
| Префикс | `AEZA_API_PREFIX`, по умолчанию `/api/v1` |
| Формат | JSON |
| Аутентификация | Bearer JWT (модуль `backend/auth`), cookie-сессия для браузера |
| Время | ISO 8601 с часовым поясом; расчёты привязаны к `AEZA_AS_OF` |
| Деньги | целые минорные единицы + валюта, никаких `float` |
| Ошибки | `{"detail": ...}` FastAPI + доменные коды из `backend/app/domain/*` |

## Ключевые группы маршрутов

| Группа | Назначение | Права |
| --- | --- | --- |
| `/auth/*` | вход, refresh, выход | — |
| `/analytics/*` | агрегаты, риск, выручка под риском | роль аналитика |
| `/customers/*` | аккаунты и услуги | роль аналитика |
| `/insights/*` | AI-инсайты | роль аналитика |
| `/actions/*` | предложенные действия и сценарии | роль аналитика |
| `/source/snapshot` | приём снимка | токен `AEZA_SOURCE_INGEST_TOKEN` |
| `/export/*` | выгрузки | роль аналитика |
| `/ai/*`, `/model/*` | ассистент и состояние модели | роль аналитика |
| `/telegram/*` | Mini App и бот | подпись Telegram |
| `/health`, `/metrics` | эксплуатация | `AEZA_METRICS_TOKEN` для метрик |

## Идемпотентность и пределы

- Приём снимка (`PUT /api/v1/source/snapshot`) — операция замены: повтор с тем же
  телом даёт тот же результат.
- Ограничения размеров и таймаутов — `AEZA_AI_TIMEOUT_SECONDS`,
  `AEZA_OLLAMA_TIMEOUT_SECONDS`, лимиты загрузки в `backend/app/api/routes_source.py`.
- Rate limiting на уровне приложения не реализован: полагаться на прокси/шлюз. Это
  ограничение, а не недосмотр — см. [operations/deployment.md](../operations/deployment.md).

## Ошибки

| Код | Значение |
| --- | --- |
| 400 | невалидный вход (`InvalidInput` домена) |
| 401 | нет/просрочен токен |
| 403 | нет роли или нет доступа к объекту |
| 404 | объект отсутствует |
| 409 | конфликт (`ConflictError`: например, повторное действие) |
| 422 | ошибка схемы запроса |
| 503 | домен аналитики недоступен (`UnavailableAnalytics`) — честный отказ, не пустые данные |

## Как менять API

1. Изменить маршрут/схему; 2. `make openapi`; 3. обновить клиент в `frontend/src`;
4. `python backend/scripts/check_docs.py` (документация упоминает только
существующие маршруты); 5. `make verify`.
