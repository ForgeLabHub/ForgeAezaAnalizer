# Почта

Приложение поддерживает Yandex Cloud Postbox и SMTP.BZ. Провайдер выбирается через AEZA_EMAIL_PROVIDER: postbox, smtp.bz или пустое значение для автоматического выбора настроенного провайдера.

Для Postbox укажите POSTBOX_SMTP_USERNAME, POSTBOX_SMTP_PASSWORD и POSTBOX_FROM_EMAIL. Для SMTP.BZ укажите SMTP_BZ_API_KEY и SMTP_BZ_FROM_EMAIL. Настройки отправителя и тайм-аутов приведены в .env.example.

Статус конфигурации можно проверить через авторизованный GET /api/v1/email/status. Контролируемое тестовое письмо отправляется через POST /api/v1/email/test; укажите адрес, к которому у вас есть доступ, и подтвердите отправку в теле запроса.

Почтовые секреты храните в окружении. Если выбранный провайдер не настроен, приложение не отправляет письма.
