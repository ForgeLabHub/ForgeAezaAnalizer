# AI-ассистент

Эндпоинт POST /api/v1/insights/ai формулирует ответ по агрегатам опубликованной аналитики. Локальная Ollama выключена по умолчанию; без неё остальные функции приложения работают.

Чтобы включить ассистент, установите Ollama, загрузите нужную модель и задайте в .env:

~~~dotenv
AEZA_LLM_ENABLED=1
AEZA_OLLAMA_URL=http://host.docker.internal:11434
AEZA_OLLAMA_MODEL=qwen2.5:7b
~~~

Адрес должен быть доступен из API-контейнера. После изменения .env выполните docker compose up -d api.

Запрос требует Bearer-токен. Модель получает агрегированные данные, не отдельные записи клиентов. Она объясняет опубликованные показатели и не пересчитывает их. Схема запроса и параметры доступны в /api/v1/docs; полный список настроек — в .env.example.
