- [AI Analyst](AI_ANALYST.md) и [агрегатный AI-ассистент](AI_ASSISTANT.md): необязательные локальные модели.
- [Почта через SMTP.BZ](EMAIL_SMTP_BZ.md): отправка писем, переменные окружения и безопасная проверка.
- [Происхождение данных](PROVENANCE_AUDIT.md): состав и проверяемая идентичность официального снимка.
