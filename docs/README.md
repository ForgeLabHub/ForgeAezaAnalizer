# Документация

Основные инструкции описывают приложение из текущего `main` и его запуск через Docker Compose.

## Начало работы

- [Разработка](DEVELOPMENT.md): окружение, команды, структура проекта.
- [Архитектура](ARCHITECTURE.md): компоненты и поток данных.
- [Развёртывание](DEPLOYMENT.md): Compose, секреты, хранение данных и production stand.
- [API](API.md): группы маршрутов, авторизация и экспорт.
- [Проверки](TESTING.md): тестовые наборы и проверка документации.
- [Безопасность](SECURITY.md): границы доступа и настройки перед публикацией.

## Данные и аналитика

- [Данные и модель риска](DATA_AND_RISK_MODEL.md): схема снимка, денежные поля, правила score и ограничения интерпретации.
- [AI Analyst](AI_ANALYST.md) и [агрегатный AI-ассистент](AI_ASSISTANT.md): необязательные функции на локальной модели.

## Сценарии и отчёты

- [Сценарий демонстрации](DEMO_SCRIPT.md)
- `audits/` — результаты проверок конкретных состояний кода и окружения; перед применением сверяйте дату и commit.
- `research/` — исследовательские заметки.
- `deck/` — исходники и материалы презентации.

Документы, не перечисленные в этом индексе, могут описывать отдельные итерации или прежние варианты реализации. Для актуального поведения используйте код и OpenAPI текущего запуска.
