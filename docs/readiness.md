GET  /api/v1/customers/{id}          GET  /api/v1/source/snapshot

## 6. Что осталось и известные ограничения

### Ограничения данных (не дефекты)

- **Нет исторических исходов оттока** — модель rule-based, а не обученная и
  откалиброванная. Заявлений о точности нет ни в интерфейсе, ни в документации.
- **Нет динамики** — снимок описывает один момент. Вместо графика тренда показано
  актуальное распределение и прямо указано отсутствие истории.
- **Нет календаря будущих списаний** — даты продлений выводятся из `expiresAt` и
  `paymentTerm`; это оценка по доступным полям.
- **`transactions.amount` не связан с `price`** — сознательно не используется в
  расчётах.
- **Данные синтетические** — равномерное распределение статусов не имитирует реальную
  базу.

### Не проверено

- **Публикация в production не выполнялась.** Развёрнут только демонстрационный стенд
  (Compose с временным override-файлом). Домен, TLS-терминация на стороне Aéza,
  горизонтальное масштабирование и резервное копирование не настраивались.
- **Поведение на больших объёмах не измерялось.** Набор кейса — 10/30/100 записей.
  Сортировка и фильтрация выполняются в SQL, пагинация реализована, но нагрузочного
  тестирования не было.
- **Одновременный конкурентный импорт не тестировался.** Атомарность одного импорта
  проверена; сценарий двух параллельных импортов не воспроизводился.
- **Горизонтальное масштабирование не проверялось.** Один экземпляр API.

### Проверено в Docker

Стек из `docker-compose.yml` собран и запущен: все три контейнера перешли в состояние
`healthy`. Демонстрационный стенд доступен по публичному адресу из `docs/demo.md`.

## 7. Как воспроизвести

```bash
# Тесты
cd backend && python -m pytest tests/ -q

# Запуск API (из корня репозитория)
export AEZA_JWT_SECRET="$(python -c 'import secrets;print(secrets.token_urlsafe(48))')"
export AEZA_ADMIN_PASSWORD=demo123
export AEZA_ANALYTICS_FACTORY=backend.app.domain.module:create
export AEZA_SEED_DEMO_DATA=1
export AEZA_SNAPSHOT_PATH=backend/data/snapshot.json
python -m uvicorn main:app --host 127.0.0.1 --port 8000

# Запуск интерфейса
cd frontend && npm install && npm run dev
```

Вход: `analyst@aeza.test` / `demo123`. Интерфейс: <http://127.0.0.1:5173>.
Опорный момент зафиксирован (`2026-10-19T15:00Z`), поэтому числа воспроизводимы.
